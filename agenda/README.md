# 💈 Elite Barber Collective - Experience & Grooming

![Luxury Header](https://raw.githubusercontent.com/lucide-react/lucide/main/icons/scissors.svg)

Uma plataforma de agendamento de **ultra-luxo** desenvolvida para barbearias premium que buscam uma experiência digital minimalista, rápida e sofisticada.

## ✨ Diferenciais & Funcionalidades

### 🏛️ Estética Luxury Minimalist
Interface desenhada sob os princípios de design de marcas de alto luxo, utilizando uma paleta monocromática profunda, tipografia serifada clássica e micro-animações suaves.

### 📅 Agendamento Inteligente
- **Calendário Dinâmico**: Seleção intuitiva de datas com bloqueio automático de dias passados.
- **Grade de Horários Real-time**: Visualização instantânea de slots disponíveis com base na data selecionada.
- **Seleção de Serviços**: Menu de serviços com preços dinâmicos e feedback visual de seleção.

### ⏳ Fila Digital (Digital Waitlist)
- Sistema para clientes sem agendamento prévio.
- Monitoramento de posição na fila e tempo estimado de espera.
- Lista de espera pública para transparência no atendimento.

### 🛡️ Painel Administrativo (Executive Dashboard)
- **Gestão de Agenda**: Filtro por data e integração direta com WhatsApp dos clientes.
- **Resumo Financeiro**: Visualização imediata do faturamento diário previsto.
- **Dashboard de Métricas**: Monitoramento de agendamentos totais e tráfego na fila.
- **Controle de Serviços**: Cadastro e edição de preços de forma simplificada.
- **Configuração de Horários**: Gestão de horários de funcionamento e dias de folga através de um sistema de "chips" interativos.

## 🛠️ Tecnologias
Este projeto foi construído propositalmente sem dependências externas pesadas para garantir máxima performance (*zero-latency*):

- **HTML5**: Estrutura semântica e acessível.
- **CSS3 Moderno**: 
  - Variáveis (Design Tokens).
  - Flexbox & Grid para layouts responsivos.
  - Keyframe Animations para o efeito "Luxury Entrance".
- **JavaScript Vanilla (ES6+)**: Lógica de agendamento e manipulação de DOM.
- **Persistence Layer**: `localStorage` (os dados acompanham o navegador do usuário).

## 🚀 Como Executar
O sistema é uma **SPA (Single Page Application)** estática. Para rodar:

1. Clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Não requer `npm install` ou servidores complexos (funciona via File Protocol ou um servidor simples tipo `Live Server`).
